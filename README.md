# 🎬 VidPlay

Aplicação de filmes e séries desenvolvida com React e Vite, consumindo dados da API TMDB para exibição de conteúdos, trailers e informações detalhadas.

## 📸 Preview

![VidPlay](./screenshot.png)

## 🚀 Demo

https://moniquegananca88.github.io/vidplay-react-vite/

## ✨ Funcionalidades

* Catálogo de filmes populares
* Catálogo de séries
* Página de detalhes
* Exibição de trailers
* Informações sobre elenco
* Interface responsiva

## 🛠️ Tecnologias Utilizadas

* React
* Vite
* React Router DOM
* Styled Components
* JavaScript
* TMDB API
* Git e GitHub

## ⚙️ Como Executar o Projeto

```bash
git clone https://github.com/moniquegananca88/vidplay-react-vite.git

cd vidplay-react-vite

yarn install

yarn dev
```
